# Community Connect AI

Build a complete, modern, responsive web application called **MoyaAssist SA**.

## PROJECT CONCEPT

MoyaAssist SA is an AI-powered community assistance and civic productivity platform designed specifically for communities in South Africa.

The goal is to make it easier for ordinary South Africans to:

* Report community problems
* Understand municipal and public-service information
* Find relevant community services
* Turn informal complaints into structured reports
* Understand complicated government notices
* Track reported issues
* Get AI-powered guidance about community problems

The platform should demonstrate how AI can solve a practical South African community problem while improving productivity, communication, and access to information.

This is a prototype/demo application for an AI productivity project.

# AI REPORT GENERATOR

Create a button:

**"Generate Report with AI"**

The AI should transform informal descriptions into a structured report.

Example:

USER INPUT:

"There is a big water leak by the shops. It's been running for two days."

AI OUTPUT:

### Community Issue Report

**Issue Type:** Water Leak

**Location:** Near local shops

**Description:**
A water leak has reportedly been occurring near the local shops for approximately two days.

**Potential Impact:**
Water wastage and possible damage to surrounding infrastructure.

**Recommended Action:**
The relevant water services authority should investigate and repair the leak.

Allow the user to edit the generated report before saving.

Buttons:

* Edit
* Regenerate
* Copy
* Save Report

IMPORTANT AI RULE:

Never invent information that the user did not provide.

If information is missing, clearly identify it as missing.

# PROMPT ENGINEERING

Use structured prompts for the AI functionality.

## Issue Classification Prompt

The AI should:

* Read the user's description
* Identify the most appropriate issue category
* Estimate urgency
* Extract relevant information
* Identify missing information
* Never invent facts

Return structured information.

---

## Report Generation Prompt

The AI should:

* Transform informal language into professional community-report language
* Preserve the user's facts
* Improve clarity
* Identify missing information
* Never invent names, dates, locations, or events
* Keep the report concise

---

## Information Simplification Prompt

The AI should:

* Summarize the supplied information
* Use simple language
* Preserve important dates and requirements
* Identify actions the reader needs to take
* Clearly state uncertainty
* Never change the meaning of the original text

---

## Service Recommendation Prompt

The AI should:

* Understand the user's request
* Identify the type of assistance needed
* Search only the application's available service dataset
* Recommend relevant services
* Explain why each service is relevant
* Never invent organizations or contact details
