# 🇿🇦 MoyaAssist SA

**AI-Powered Community Assistance & Civic Productivity Platform**

> **Making it easier for communities to be heard.**

MoyaAssist SA is an AI-powered community-support platform designed to help South African residents report community problems, understand public-service information, and find relevant community resources.

The platform uses Artificial Intelligence to simplify everyday community-related tasks and improve the way users communicate problems and access information.

MoyaAssist SA is an **independent prototype** and is **not affiliated with or operated by any South African government department, municipality, emergency service, or public institution.**

---

## 📋 Project Overview

Many community members encounter problems such as potholes, water leaks, electricity issues, broken streetlights, waste collection problems, and damaged public infrastructure.

Communicating these problems clearly can sometimes be difficult. Residents may also encounter complicated public-service information that is difficult to understand quickly.

MoyaAssist SA addresses this problem by providing an AI-powered platform that helps users:

* Describe community problems in simple language
* Automatically classify reported issues
* Convert informal descriptions into structured reports
* Understand complicated public-service information
* Find relevant community services
* Ask an AI assistant for community-related guidance
* Save and track community reports

The project demonstrates how AI can be applied to a real-world South African community problem while considering productivity, usability, and responsible AI.

* Broken streetlights
* Missed waste collection
* Illegal dumping
* Damaged roads
* Damaged public infrastructure

In addition, public-service notices and information can sometimes contain complex language that makes them difficult for residents to understand.

MoyaAssist SA provides AI-powered tools that help simplify these tasks.

# 💡 Solution

MoyaAssist SA combines several AI-powered productivity tools into one platform.

A user can describe a problem naturally, for example:

> "There is a big water leak near the shops and it has been running for two days."

The system can identify the issue as a **water leak**, determine relevant information, and generate a structured report that the user can review and edit.

The platform can also simplify complicated information and help users find relevant community resources.

# ✨ Features

## 1. 🤖 AI Community Issue Classification

The AI analyzes a user's description and identifies the most appropriate category.

Supported examples include:

* Potholes
* Water leaks
* Water outages
* Electricity problems
* Streetlight problems
* Waste collection
* Illegal dumping
* Road problems
* Damaged infrastructure
* Other

The AI can also estimate urgency and identify information that may be missing.

---

## 2. 📝 AI Report Generator

Users can describe a problem in everyday language.

The AI transforms the description into a structured community report containing:

* Issue type
* Location
* Description
* Potential impact
* Recommended action

The generated report can be reviewed and edited before being saved.

The AI is instructed not to invent information that the user did not provide.

---

## 3. 💬 AI Community Assistant

MoyaAssist includes an interactive AI assistant that can help users with questions such as:

* "How do I report a pothole?"
* "What information should I include in my report?"
* "Help me write a community complaint."
* "Explain this public-service notice."
* "What type of community service should I look for?"

The assistant provides clear, accessible responses and explains its limitations.

---

## 4. 📄 Information Simplifier

Users can paste complicated information into the **Understand This** tool.

The AI can produce:

### Simple Summary

A concise explanation of the information.

### What Does This Mean?

An explanation using easier language.

### What Do I Need To Do?

A list of potential actions identified from the supplied information.

### Important Dates

Relevant dates found in the supplied content.

### Important Contacts

Contact information included in the supplied content.

The original information should always be checked when the information is important.

---

## 5. 🔎 AI Community Service Finder

Users can describe what type of assistance they need.

For example:

> "I need help finding food support."

The AI identifies the type of assistance required and recommends relevant services from the application's available service directory.

The AI must only recommend services contained in the application's dataset.

# 🧠 AI & Prompt Engineering

Prompt engineering is an important part of MoyaAssist SA.

The AI workflows use structured prompts designed to produce useful and reliable results.

### Issue Classification

The AI is instructed to:

* Analyze the user's description
* Identify the issue category
* Estimate urgency
* Extract relevant information
* Identify missing information
* Avoid inventing facts

### Report Generation

The AI is instructed to:

* Preserve the user's original facts
* Improve clarity
* Structure the information professionally
* Identify missing information
* Avoid inventing names, dates, locations, or events

### Information Simplification

The AI is instructed to:

* Summarize supplied information
* Use simple language
* Preserve important dates
* Preserve important requirements
* Identify potential actions
* Avoid changing the meaning of the original information

### Service Recommendations

The AI is instructed to:

* Understand the user's request
* Identify the type of assistance required
* Search the available service dataset
* Recommend relevant services
* Explain why a service may be relevant
* Never invent organizations or contact details

# 🛡️ Responsible AI

MoyaAssist SA is designed with responsible AI principles in mind.

## AI Limitations

Artificial Intelligence can misunderstand information or produce inaccurate responses.

AI-generated information should therefore be reviewed by the user.

## Human Verification

Users should verify important information using appropriate official sources before taking action.

## No Government Affiliation

MoyaAssist SA is an independent prototype and does not represent any South African government department or municipality.

## Privacy

Users should avoid entering unnecessary sensitive personal information.

## AI Bias

AI systems can contain biases depending on their training data and inputs.

Users should consider AI recommendations critically.

## No Fabricated Information

The AI should not invent:

* Organizations
* Contact details
* Locations
* Dates
* Government actions
* Report submissions
* Emergency responses

---

# 🚨 Emergency Safety

MoyaAssist SA is **not an emergency response service**.

If a user describes an immediate emergency or situation involving immediate danger, the application should direct the user to contact the appropriate emergency service directly.

The AI must never claim that it has dispatched emergency services or contacted authorities unless an actual verified integration exists.

# ⚙️ Setup Instructions

## Prerequisites

Install the following:

* Node.js
* npm
* Git (optional)

Verify Node.js:

```bash
node --version
```

Verify npm:

```bash
npm --version
```

---

## Installation

Clone or download the project.

Navigate into the project directory:

```bash
cd moyaassist-sa
```

Install dependencies:

```bash
npm install
```

---

# 🔐 Environment Variables

If the application uses an external AI API, create a `.env` file in the project root.

Example:

```env
VITE_AI_API_KEY=your_api_key_here
```

Use the actual environment variable required by the final implementation.

### Important

Never commit real API keys to GitHub.

Never place private API keys directly inside frontend source code.

---

# ▶️ Running the Application

Start the development server:

```bash
npm run dev
```

Lovable/Vite will provide a local development address, typically similar to:

```text
http://localhost:5173
```

Open the displayed address in a web browser.
